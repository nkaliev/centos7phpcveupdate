# Обновление PHP на CentOS 7

Навык Codex для установки исправлений безопасности PHP **8.2, 8.3, 8.4 и 8.5** из совместимых EL7 RPM с сохранением установленной ветки и минимальным изменением зависимостей.

## Установка и вызов

Скопируй каталог [centos7-php-update](centos7-php-update/) в `~/.codex/skills/`.

Вызов: `$centos7-php-update`.

[Инструкция навыка](centos7-php-update/SKILL.md) описывает выбор исправленной сборки, проверку подписей и зависимостей, резервирование, ограниченную транзакцию, применение к Apache/mod_php или PHP-FPM и проверку приложения.

PECL и остальное ПО сохраняются, если зависимости позволяют. Переход между ветками PHP требует отдельного решения. Версии и доступность пакетов проверяются перед установкой.

RocketSky — сторонний поставщик RPM. Обновление PHP не обеспечивает сопровождение всей CentOS 7.
